DEPLOY (GitHub Desktop)
1. BACK UP your local repository first.
2. Extract this ZIP and copy all files/folders into your local GitHub Pages repo ROOT (e.g., D:\Portofolio).
3. Important: MERGE the assets folder and overwrite shared files. Do not delete your own existing assets/certificates or other files.
4. Open GitHub Desktop: check Changes, Commit to main, Push origin.
5. After publishing, hard-refresh browser (Ctrl+Shift+R) and check layout on desktop/mobile.

To edit project presentation/demo/github links: edit the card data-presentation, data-demo, data-github in index.html.
To replace a project image, replace its SVG in assets/projects (or change data-image and <img src>). 
All project certificates are PDFs linked directly; no inactive image lightbox buttons.
